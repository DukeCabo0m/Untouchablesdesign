# Untouchables.fr

Site web officiel de la communauté francophone Untouchables - Fans de Korn.

## 🎸 À propos

Site React + Vite + Supabase pour la communauté de fans de Korn en France.

## 🚀 Développement

```bash
# Installer les dépendances
pnpm install

# Lancer le serveur de développement
pnpm dev

# Build pour production
pnpm build
```

## 📁 Structure

```
src/
├── app/
│   ├── components/     # Composants React
│   ├── pages/         # Pages de l'application
│   ├── contexts/      # Contexts React
│   ├── hooks/         # Custom hooks
│   ├── utils/         # Utilitaires
│   └── routes.tsx     # Configuration des routes
├── styles/            # Styles CSS
└── main.tsx          # Point d'entrée

supabase/
└── functions/        # Edge Functions Supabase

utils/
└── supabase/         # Configuration Supabase
```

## 🔧 Technologies

- React 18
- TypeScript
- Vite
- Tailwind CSS v4
- Supabase (Backend, Auth, Storage)
- React Router
- Framer Motion
