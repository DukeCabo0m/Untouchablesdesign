📅 Date : 16 mars 2026
🎯 Problème : Erreur HTTP 401 sur appels Supabase Edge Functions
✅ Statut : RÉSOLU

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 DIAGNOSTIC

Cause racine identifiée :
→ Les Supabase Edge Functions exigent TOUJOURS un header Authorization
→ Sans ce header, Supabase retourne 401 avant d'atteindre le code de l'app

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 SOLUTION APPLIQUÉE

Fichier modifié : /src/app/pages/Admin/AdminInitPage.tsx

AVANT (❌) :
```typescript
const response = await fetch('https://...supabase.co/.../health');
// Pas de header Authorization
```

APRÈS (✅) :
```typescript
const response = await fetch('https://...supabase.co/.../health', {
  headers: {
    'Authorization': `Bearer ${publicAnonKey}`
  }
});
```
